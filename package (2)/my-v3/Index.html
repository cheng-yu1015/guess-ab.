幾 A 幾 B，雲端記得。

四位數幾 A 幾 B。用相同代號回來，讀取原本的局與猜測歷程。

代號不是登入或密碼。知道同一代號的人就能讀取、操作同一份紀錄；請使用課堂測試代號，不填姓名、Email 或密碼。

請輸入代號讀取雲端資料。

用代號進入

3～24 個英文字母、數字、底線或連字號；英文不分大小寫。請記下這個代號。

共 0 局猜對 0 局

還沒有遊戲

答案是 4 個「不重複」的數字，可以 0 開頭（例如 0123）。A＝數字與位置都對；B＝數字對、位置不同。4A0B 就過關。

請先開新局。

每次有效猜測自動存到雲端。看到「已儲存」再離開；輸入框內尚未送出的數字不會存檔。
